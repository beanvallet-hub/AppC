
# FCM SETUP

## Create Firebase project 

- login to firebase console
- create a new project
- create a new android app
- download google service config json file


## install google services

- install react-native-firebase 

- follow instructions to setup google services
https://rnfirebase.io/#installation-for-react-native-cli-non-expo-projects

- open android studio and resync build 


## configure backend 

- install firebase-admin

- create a firebase service account

- download service account key file

- Use Key file to initialize firebase/app



## Create fcmservice 

- getToken, send token to backend , token refresh

- register for foreground and background messages

- Notification display using notifee
