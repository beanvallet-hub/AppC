# Getting Started



### Install dependencies

```sh
npm install
```

### Create a .env file in the root of the project directory (use the sample.env file)
Add backend api url to .env file

## Please start the backend service before going forward.


### Start Metro
To start the Metro dev server, run the following command from the root of your React Native project:

```sh
npm start
```

### Start Application
On a seperate terminal

```sh
npm run android
```


### reset Metro/babel cache
```
npx react-native start --reset-cache
```
